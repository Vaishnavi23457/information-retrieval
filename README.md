# Human Relevance Judgment System
## With SciFact Benchmark Support

An end-to-end Information Retrieval evaluation pipeline that lets users:

1. Search a document collection with TF-IDF cosine similarity
2. Rate each retrieved document using a 4-point relevance scale
3. Automatically compute **Precision@k**, **Recall@k**, **MAP**, and **NDCG@k**

---

## Quick Start

```powershell
# 1. Navigate to the project folder
cd human-relevance-judgment

# 2. Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch the app
streamlit run app.py
```

The browser will open automatically at `http://localhost:8501`.

### Optional: Add the SciFact dataset

```powershell
# Install BEIR (one-time)
pip install beir

# Download and convert SciFact (~30 MB, takes ~2 minutes)
python scifact_import.py

# Relaunch the app — SciFact will appear in the dataset selector
streamlit run app.py
```

### Run tests

```powershell
python test_suite.py
```

## Relevance Grade Scale

| Grade | Label            | Meaning                                     |
|-------|------------------|---------------------------------------------|
| 3     | Highly Relevant  | Directly answers the query; comprehensive   |
| 2     | Relevant         | Clearly related; useful for the need        |
| 1     | Partially Relevant | Tangentially related; partially useful   |
| 0     | Not Relevant     | Off-topic                                   |

Binary relevance threshold: **grade ≥ 2** counts as *relevant* for Precision, Recall, and MAP.  
NDCG uses all four grades.

## Metrics Formulas

### Precision@k
```
P@k = (Relevant docs in top-k) / k
```

### Recall@k
```
Recall@k = (Relevant retrieved in top-k) / (Total relevant in judged pool)
```

### Average Precision (AP) → MAP
```
AP@k = Σ [P@i × rel(i)] / total_relevant
MAP  = (1/Q) × Σ AP(q)
```

### NDCG@k
```
DCG@k  = Σ (2^rel_i − 1) / log₂(i+1)
NDCG@k = DCG@k / IDCG@k
```
